🎯 核心功能（点击展开详情）
🔍
竞品数据采集
自动抓取竞品价格、销量、Review、BSR排名，多维度对比分析
点击展开详情 ▼
输入：关键词/类目/竞品ASIN列表
采集字段：标题、价格、评分、Review数、BSR排名、卖家类型、上架时间、变体数
输出：Excel对比表 + 趋势变化标记 + 异常波动预警
技术方案：Selenium模拟浏览器 / 亚马逊SP-API官方接口 / 第三方数据API
适用场景：新品竞品调研、日常竞品监控、价格战预警
预估耗时：50条竞品约2-3分钟
📊
商品数据整理
批量处理商品信息，自动清洗、去重、格式化，一键导出Excel/CSV
点击展开详情 ▼
输入：多平台导出的原始数据（亚马逊/速卖通/Shein/PDD）
处理逻辑：字段统一映射 → 重复数据去重 → 缺失值填充 → 异常值标记 → 单位统一转换
输出：标准化Excel（多Sheet：原始/清洗/统计） + 数据质量报告
技术方案：Pandas数据处理 + openpyxl Excel生成 + 正则表达式清洗
适用场景：多平台数据合并、月度数据汇总、数据上报前整理
预估耗时：1000条数据约10秒
🎯
智能选品指标
基于市场容量、竞争度、利润率、季节性多维度评分，辅助选品决策
点击展开详情 ▼
评分维度（5维）：
　① 市场容量：月搜索量、市场规模、增长趋势
　② 竞争度：卖家数量、头部集中度、新进入者比例
　③ 利润率：客单价、采购成本、FBA费用、广告占比
　④ 季节性：销量波动系数、旺季月份、库存风险
　⑤ 合规风险：专利风险、侵权概率、类目审核要求
输出：选品评分表（0-100分） + 各维度雷达图 + 推荐/谨慎/回避建议
适用场景：新品开发选品、类目机会挖掘、供应链选品验证
📈
广告模拟分析
模拟SP广告投放效果，ACOS/ROAS预估，关键词竞价建议，预算分配优化
点击展开详情 ▼
输入：商品客单价、毛利率、目标ACOS、关键词列表及搜索量
模拟指标：预估曝光量、点击率(CTR)、转化率(CVR)、单次点击成本(CPC)、ACOS、ROAS、广告订单占比
关键词策略：大词/长尾词/精准词分层建议，否定关键词推荐，竞价区间建议
预算分配：自动广告/手动广泛/手动词组/手动精准的预算比例建议
输出：广告投放方案表 + 效果预估 + 优化建议清单
适用场景：新品广告启动方案、广告优化复盘、预算调整决策

🔧 环境配置

                        
安装Python 3.9+（推荐3.10）

                        
安装依赖包：

                        
pip install pandas selenium requests openpyxl

                        
下载ChromeDriver（匹配Chrome版本）

                        
安装影刀RPA客户端（如需可视化流程）

                        
配置亚马逊SP-API开发者凭证（如需官方API）

                    

                    

                        
▶️ 运行方式

                        
方式一：直接运行Python脚本

                        
python competitor_scraper.py --keyword "wireless earbuds"

                        
方式二：影刀RPA调用Python

                        
在影刀中添加"执行Python"节点，传入参数

                        
方式三：定时任务自动运行

                        
Windows任务计划程序 → 每日9:00触发

                    

                    

                        
⚠️ 常见问题

                        
被反爬拦截：添加代理IP池、设置随机延迟、使用无头浏览器模式

                        
元素定位失败：页面结构变化，更新CSS Selector/XPath，建议使用相对定位

                        
数据不准：多数据源交叉验证，设置数据校验规则，异常值人工复核

                        
被封号风险：控制采集频率（间隔≥3秒），使用紫鸟等防关联浏览器，遵守平台robots协议
